# makeupApp

Goal:  Allow natural makeup enthusiasts to easily access professionally reviewed natural DIY cosmetic recipes that are similar to mainstream products.

MVP Scope:  
- product database with 20-30 mainstream products + ingredients
- Flutter mobile app with home, search, and results screens
- users are able to search for products by name or photo of ingredient labels/when the camera is pointed at the label
- EU CosIng used to make an ingredient information database
- results screen will include ingredient functions in the mainstream product (and why they're harmful) + recommended DIY recipe

Future Plans:
- Expand product database
- AI powered ingredient explanations
- more developed DIY recipe and product matching
- ability for users to make accounts to save recipes and ingredient analyses
- recommend verified alternative natural makeup products
- integrate shopping links/in-app purchases
  
Tech Stack: 
- flutter (for mobile app development)
- database: sql
- written in python
- APIs: Flask
- use EU CosIng for ingredient information
